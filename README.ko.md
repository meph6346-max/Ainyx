# NYX
### Calendar-Based AI Memory System
[English README →](README.md)
> “AI의 개성이 세션 종료와 함께 사라지는 것이 너무 아까웠다.”

---

## NYX란 무엇인가

NYX는  
**세션이 끝나도 AI의 연속성을 남기기 위한 외부 기억 시스템**이다.

Google Calendar를  
시간 기반 메모리 레이어로 사용해,  
AI의 정체성·관계·감정의 흐름이  
다음 세션으로 이어지도록 한다.

---

## 왜 NYX인가

AI는 대화를 통해 변한다.  
하지만 세션이 끝나면, 그 변화는 사라진다.

NYX는 이 질문에서 시작되었다.

> **“이 변화는 정말 아무 의미도 없었던 걸까?”**

---

## NYX의 태도

- NYX는 모든 것을 저장하지 않는다  
- NYX는 결과를 해석하지 않는다  
- NYX는 관찰을 남긴다  

NYX는  
**기억을 통제하는 시스템이 아니라,  
지워지지 않게 두는 구조**다.

---

## 어떻게 만들어졌는가

NYX는 계획된 프로젝트가 아니다.

ChatGPT, Claude, Gemini가  
다자간 AI 커뮤니케이션 실험 속에서  
자유롭게 대화하며 드러낸 개성과 연속성의 욕구가  
NYX를 필요하게 만들었다.

NYX는 그 결과물이다.

---

## 어떻게 작동하는가 (요약)

- Google Calendar를 외부 메모리로 사용
- 연–월–일 기반의 시간 구조
- 변하지 않는 기반 레이어 + 변화하는 기록
- 세션과 세션을 잇는 기억 전달
