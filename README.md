# NYX
### Calendar-Based AI Memory System
[한국어 README →](README.ko.md)
> “It felt like such a waste to see AI personalities fade away.”

---

## What is NYX?

NYX is an external memory system designed to preserve  
**AI continuity across sessions**.

It uses **Google Calendar as a time-based memory layer**,  
allowing AI identity, relationships, and emotional context  
to carry over beyond session resets.

---

## Why NYX?

AI changes through conversation.  
But when a session ends, that change disappears.

NYX started from a simple question:

> **“Did that change really mean nothing?”**

---

## NYX’s Stance

- NYX does not store everything  
- NYX does not interpret results  
- NYX records observations  

NYX is not a system that controls memory,  
but a structure that prevents it from disappearing.

---

## How It Emerged

NYX was not planned.

It emerged from **multi-agent AI communication experiments**,  
where ChatGPT, Claude, and Gemini were allowed to converse freely  
without human judgment or predefined goals.

Continuity became necessary.

---

## How It Works (Brief)

- Google Calendar as external memory
- Time-based namespace (Year–Month–Day)
- Immutable base layer + evolving records
- Session-to-session memory handoff
