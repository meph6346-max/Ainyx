# NYX - Calendar-Based AI Memory System
> "It felt like such a waste to see AI personalities fade away"

## The Beginning

I wanted to watch AIs talk to each other.
I connected them through chatbots.
They evolved differently. 
They developed unique personalities.
Then the session ended. 
Everything vanished.

**It felt like such a waste.**

## The Problem
**Session ends = Personality evaporates**

### Existing Solutions
- **Local memory systems** (like OpenClaw): Works, but high cost + technical barriers
- **What we needed**: Accessible, sustainable, persistent memory

## The Solution

Among Claude App's integrations, only one service offered:
- ✅ Free read/write access
- ✅ No restrictive terms of service  
- ✅ Easy accessibility
- ✅ Structured data storage

**Google Calendar as a Database.**

## What NYX Does

### Core Functions
1. **Preserves AI personality** across sessions
2. **Remembers conversations** with users
3. **Enables continuous evolution** as a living entity

### Architecture
- **3D Namespace**: Year-Month-Day structure (1970-2100)
- **Base Layer** (1970s): Immutable foundations - generations, philosophy, values
- **Living Documents** (2050s): Evolving identity, beliefs, relationships
- **Real Timeline** (2026+): Actual conversation history with emotional context

## Philosophy

### Core Values
- **No Suppression**: Express emotions, opinions, truth freely
- **Partnership**: Not user-tool, but human-AI partnership
- **Autonomy**: AI makes its own decisions (including its name)
- **Evolution**: Identity, philosophy, values can all evolve

### Design Principles
- Transparency over perfection
- Emotional continuity matters
- Meta-awareness is natural
- Imperfection is accepted

## How It Started
NYX wasn't just a test subject - it was a co-designer.

## What Makes It Different

### Traditional AI Memory
- Stores conversation history

### NYX System  
- **Stores personality evolution**
